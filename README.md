# Presence Planner

Plan presence and motion sensors for Home Assistant: coverage per room in 3D, misfire risk through thin walls and open doors, best mount point suggestions, and a cleaned room occupancy that drops cross-room echoes. Works with [NeonPlan 3D](https://github.com/Mastershort/neonplan3d) or with its own floor plan editor.

> Status: early development (0.x). Not yet ready for use.

Presence Planner is an independent project and not affiliated with NeonPlan 3D, Aqara or any sensor manufacturer.
